# Habit Ring

A habit tracker that runs entirely in the browser. No accounts, no API keys, no build step.

**Live demo:** [https://invenitur42.github.io/habit-ring/](https://invenitur42.github.io/habit-ring/)

## What you can do

- Add habits with a color and which days they apply
- Check off today
- See streaks and last-30-day completion
- Browse a month calendar for the selected habit
- Export your data as JSON

Data is stored in `localStorage` on your machine.

## Files

| File | Role |
|------|------|
| `index.html` | Markup |
| `styles.css` | Layout and theme |
| `app.js` | Habits, streaks, calendar |

Open `index.html` locally if you do not want to use GitHub Pages.
